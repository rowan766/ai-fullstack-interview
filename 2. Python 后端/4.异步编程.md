## 异步基础

### 1. 🔥 同步、异步、并发、并行

**简要总结：**

- 同步：等待当前任务完成再继续
- 异步：等待 IO 时让出执行权
- 并发：多个任务在一段时间内交替推进
- 并行：多个任务在同一时刻同时执行
- asyncio 是单线程并发，不是多核并行

**面试口语：**

异步不是让 CPU 同时执行多个 Python 任务，而是在 IO 等待时把控制权让出去，让事件循环调度其他协程。它适合网络请求、数据库访问、文件 IO 这类等待多的场景。

**底层原理 / 背后逻辑：**

同步模型里，一个请求等待数据库时，线程也跟着阻塞。异步模型里，协程遇到 `await` 会挂起，事件循环继续执行其他已就绪任务。等 IO 完成后，再恢复原协程。它提升的是 IO 密集型场景的吞吐，而不是 CPU 计算速度。

### 2. 🔥 async / await

**简要总结：**

- `async def` 定义协程函数
- 调用协程函数得到 coroutine 对象
- `await` 等待 awaitable 完成
- `asyncio.run()` 启动事件循环运行入口协程

**面试口语：**

`async def` 调用后不会马上执行完整函数体，它返回一个协程对象。只有被 `await`、包装成 Task，或交给事件循环运行时，协程才会推进。

```python
import asyncio

async def fetch_user(user_id: int):
    await asyncio.sleep(1)
    return {"id": user_id}

async def main():
    user = await fetch_user(1)
    print(user)

asyncio.run(main())
```

### 3. 🔥 Event Loop

**简要总结：**

- 事件循环负责调度协程、回调和 IO 事件
- 就绪任务会被执行
- 遇到 await 挂起当前协程
- IO 完成后任务重新进入就绪队列

**面试口语：**

事件循环可以理解成调度器。它不断取出可以执行的任务，执行到任务主动让出控制权，再切换到其他任务。异步并发能成立，关键就是协程在等待 IO 时不会占着线程不放。

**底层原理 / 背后逻辑：**

操作系统提供了 IO 多路复用能力，比如 epoll、kqueue、IOCP。事件循环会注册 socket 等 IO 事件，当某个 IO 就绪时，事件循环恢复对应协程执行。Python 层看到的是 `await`，底层本质是事件通知和任务调度。

### 4. 🔥 coroutine / Task / Future

**简要总结：**

- coroutine：协程对象，描述异步逻辑
- Task：把协程交给事件循环调度
- Future：表示未来某个结果
- `create_task` 会让协程并发推进

**面试口语：**

协程对象只是一个可等待对象，不会自动并发。`create_task` 会把协程包装成 Task 并注册到事件循环里，这样多个任务才能交替执行。

```python
async def main():
    task1 = asyncio.create_task(fetch_user(1))
    task2 = asyncio.create_task(fetch_user(2))

    result1 = await task1
    result2 = await task2
    print(result1, result2)
```

### 5. ⭐ gather / wait / as_completed

**简要总结：**

- `gather` 并发执行并按传入顺序返回结果
- `wait` 返回 done 和 pending 集合
- `as_completed` 谁先完成先处理谁
- 选择取决于是否关心结果顺序和任务状态

**面试口语：**

如果只是并发请求并收集结果，用 `gather` 最方便；如果要控制超时、取消未完成任务，用 `wait`；如果想哪个任务先完成就先处理哪个，用 `as_completed`。

```python
results = await asyncio.gather(
    fetch_user(1),
    fetch_user(2),
    fetch_user(3),
)
```

### 6. 🔥 异步中的阻塞问题

**简要总结：**

- `time.sleep` 会阻塞事件循环
- 同步数据库驱动会阻塞事件循环
- CPU 大计算会阻塞事件循环
- 应使用异步库或 `run_in_executor`

**面试口语：**

异步代码里最常见的坑是调用阻塞函数。比如在 FastAPI 的 async 接口里用同步数据库驱动，整个事件循环都会被卡住，其他请求也受影响。

```python
import time
import asyncio

async def bad():
    time.sleep(1)  # 阻塞事件循环

async def good():
    await asyncio.sleep(1)  # 让出控制权
```

### 7. ⭐ 异步超时、取消和限流

**简要总结：**

- `asyncio.wait_for` 控制超时
- `task.cancel()` 取消任务
- `Semaphore` 控制并发数量
- 防止一次性打满下游服务

**面试口语：**

异步并发不能无限开。比如同时请求 1000 个下游接口，可能把对方或自己打挂。可以用 `Semaphore` 限制同时执行数量，并给每个请求设置超时。

```python
sem = asyncio.Semaphore(10)

async def limited_fetch(url: str):
    async with sem:
        return await asyncio.wait_for(fetch(url), timeout=3)
```
